# 电商用户近期购买行为分类实验

这是《人工智能基础及应用》的机器学习实验。程序用逻辑回归和决策树比较分类效果，并保存准确率曲线和混淆矩阵。

## 数据说明

原始数据是 `E-commerce Customer Behavior.csv`。文件没有直接的“是否购买”字段，而且所有顾客都有购买记录。程序把 `Days Since Last Purchase <= 30` 定义为“近 30 天购买过”（标签 1），否则为 0。因此本实验预测的是**近期购买情况**，不是未来是否会购买。原始 CSV 不会被修改。

程序在内存中排除顾客编号、性别、城市、满意度和用于生成标签的距上次购买天数，再使用其余字段训练模型。

## 运行

```powershell
python -m pip install -r requirements.txt
python 购买行为分类实验.py
```

程序运行后会在当前目录生成 `准确率变化曲线.png`、`逻辑回归_混淆矩阵.png` 和 `决策树_混淆矩阵.png`。实验过程、结构图、流程图和结果分析见 `购买行为分类实验_光电2505倪昊1406250303.docx`。

## 分步对照实验

四个脚本彼此独立，可以依次运行并截图，用于写报告中的“基线和三步改进”：

```powershell
python 00_多数类基线.py
python 01_只用年龄.py
python 02_加入累计消费.py
python 03_增加树深度.py
```

每个脚本都会打印验证准确率、测试准确率、精确率和召回率。数据划分与随机种子相同，所以结果可以直接比较。

| 阶段 | 验证准确率 | 测试准确率 |
| --- | ---: | ---: |
| 多数类基线 | 0.643 | 0.643 |
| 只用年龄 | 0.786 | 0.786 |
| 加入累计消费金额 | 0.871 | 0.829 |
| 树深度增至两层 | 0.943 | 0.971 |

这些是固定随机种子 42 下的实际结果；参数变化不一定总能改善所有指标。例如加入累计消费金额后，测试召回率从 1.000 降为 0.778。
